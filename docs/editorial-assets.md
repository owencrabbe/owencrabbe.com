# Editorial artwork

These original AI-generated illustrations were supplied for Owen Crabbe’s personal portfolio. They were created through Higgsfield and visually reviewed before integration. They depict abstract paper, thread and a notebook, rather than a product screenshot, physical product, research measurement or client work. Each has an adjacent “AI-generated editorial illustration” caption.

The repository contains the supplied lightweight WebP encodings, unchanged:

| File | Dimensions | Bytes | Placement |
| --- | --- | ---: | --- |
| `public/images/owen-evidence-landscape.webp` | 1920 × 1088 | 144,324 | Homepage introduction |
| `public/images/phroneme-research-landscape.webp` | 1920 × 1088 | 131,996 | Homepage Phroneme entry |

The hero image loads with high priority. The Phroneme image loads lazily. Both declare intrinsic dimensions and decode asynchronously. They are decorative, have empty alt text and remain separate from real HTML headings and project claims. Print styling hides the illustrations. PNG masters, transfer identity and the source archive are retained outside the published site.

The supplied portrait concept clip and fitness-curation still are not used in this portfolio change. No video, remote image host, third-party script, paid service or new runtime dependency is required.
